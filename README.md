# jurnalpedia-bio

This repo contains the source code for the landing page of Jurnalpedia, an app that helps students and researchers understand the ins and outs of academic publishing through guidance, journal tips, and academic insights. This landing page serves as Jurnalpedia's introduction page for fellow #ResearchWarriors, and also applies to the bio.jurnalpedia.my.id landing page.

Situs publik **Jurnalpedia** (ensiklopedia jurnal, tips publikasi, dan layanan pendampingan publikasi untuk mahasiswa dan peneliti). Dilayani lewat GitHub Pages di `https://bio.jurnalpedia.my.id`.

| Bagian | Isi |
|---|---|
| `index.html` | Beranda link-in-bio: web, aplikasi Android, komunitas, email, WhatsApp, layanan, dan media sosial |
| `services/` | Layanan dan produk: produk digital, pendampingan publikasi jurnal, promosi, kebijakan layanan |
| `privacy-policy/`, `terms-conditions/`, `disclaimer/`, `delete-account/` | Halaman hukum dan penghapusan akun |
| `assets/` | Gaya (mode gelap otomatis + tombol), skrip kecil, logo dan ikon lokal |
| `sitemap.xml`, `robots.txt`, `app-ads.txt`, `CNAME` | SEO, berkas iklan aplikasi, dan domain khusus |

Situs statis murni (HTML, CSS, dan JS tanpa build step). Situs ini hanya mengarahkan ke aplikasi, web, dan WhatsApp; font dan ikon dimuat dari Google Fonts dan cdnjs.
