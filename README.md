# jurnalpedia-bio

This repo contains the source code for the landing page of Jurnalpedia, an app that helps students and researchers understand the ins and outs of academic publishing through guidance, journal tips, and academic insights. This landing page serves as Jurnalpedia's introduction page for fellow #ResearchWarriors, and also applies to the bio.jurnalpedia.my.id landing page.

The public site for **Jurnalpedia** (a journal encyclopedia, publishing tips, and publication coaching for students and researchers), served through GitHub Pages at `https://bio.jurnalpedia.my.id`.

| Part | Contents |
|---|---|
| `index.html` | Link-in-bio home page: website, Android app, community, email, WhatsApp, services, and social media |
| `services/` | Services and products: digital products, journal publication coaching, promotion, service policy |
| `privacy-policy/`, `terms-conditions/`, `disclaimer/`, `delete-account/` | Legal and account deletion pages |
| `assets/` | Styles (automatic dark mode plus a toggle), a small script, and the local logos and icons |
| `sitemap.xml`, `robots.txt`, `app-ads.txt`, `CNAME` | SEO, app ads file, and custom domain |

A plain static site (HTML, CSS, and JS with no build step). It only links out to the app, website, and WhatsApp. Fonts and icons are loaded from Google Fonts and cdnjs.
